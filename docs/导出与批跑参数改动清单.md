# 导出与批跑参数改动清单（v4.13 已实施）

记录日期：2026-11-17，已按用户补充更新名称、参数提示及单 XLSX 导出范围。用户确认后，v4.13 已按本清单实施；服务未启动，部署需更新代码并重启原服务。默认15张/3fps的选帧规则不变。下列约束核对记录描述修改前状态，字段要求与导出范围已落实。

## 已确认的参数与展示改动

| 项目 | 要求 |
| --- | --- |
| 实验名称 | 默认由任务创建时间与原始输入文件名组合，如“2026-11-17 14:30:12_0831.xlsx”，保留用户修改名称的能力；时间使用 Asia/Shanghai。新建重跑用本次创建时间和原输入文件名生成新默认名，不反复追加“重跑” |
| 最多保留张数 | 将实验链路的 10 / 15 下拉框改为自填整数，默认 15，用于测试不同上限；不能仅改输入框却仍在内部强制截到 15 |
| 每秒采样帧数 | 增加可填写参数，默认 3；指固定采样频率，变化点和首尾仍可额外产生候选，总候选数不等于时长乘此值 |
| 评分策略 | 新实验运行固定使用新增比例，不再提供旧权重切换；新建重跑同样执行比例策略。历史结果保留当时评分和记录，base 保持冻结 |
| 批次配置标识 | 在批次列表和批次详情顶部显示实际配置，例如“实验 · 版本号 · 新增比例 · 最多 15 张 · 3 帧/秒”；开始前表单明确显示待运行值 |
| 配置保存 | 保存每批参数和每题实际配置；详情与导出读取保存的值，不能用当前默认值推断历史。缺失时注明未记录 |
| 修改时机 | 开始后本批配置固定，修改参数通过新建重跑完成，不覆盖旧结果；新建重跑在开始前展示并允许修改生效值 |

## 参数约束与输入提示

核对当前实现：实验 `max_frames` 要求 2～15 的整数，开始 API 另限制为 5 / 10 / 15；选择器和记录还有多处固定 15 截断。当前 `sample_fps` 检查大于 0，没有必须整数的要求，也没有明确的固定最高值。这些是当前约束，不是把旧的 15 上限继续带入新输入框的理由。

已实施的提示与校验：

| 输入 | 默认 | 有效值与字段提示 |
| --- | --- | --- |
| 最多保留张数 | 15 | “整数，至少 2 张；首尾计入总数，实际输出可以少于上限。”不再固定最多 15，允许测试其他上限 |
| 每秒固定采样帧数 | 3 | “大于 0，可填小数，例如 0.5、2.5；变化点与首尾可能额外取图。”不强制整数，不人为新增未经讨论的固定最高值 |

两项均拒绝空值、布尔值、非数字及非有限数字；张数不接受非整数，采样率不接受零或负数。页面与 API 使用一致的校验和清楚的错误提示，不静默取整或夹到旧范围。默认 15 是初始填写值，不再作为实验算法硬编码的最高容量。较高采样率会增加候选和开销，超过源视频帧率不会增加真实画面信息，作为字段旁简短说明。

## 已确认的导出范围：只导出一个 XLSX

在批次详情增加“导出结果”按钮，默认导出当前查看链路的本批结果，双链路分别导出，不做步骤对齐。用户已明确不需要 ZIP、图片文件、逐帧明细或单独 JSON。下面的两张工作表位于同一个 XLSX 中。

### 批次概览

记录批次名称/编号、输入文件名、创建与导出时间、链路、算法版本和代码校验值、实际张数上限、采样率及固定比例策略。汇总成功/失败/未完成数量、平均与最长抽帧耗时、初始候选与最终输出数量、输出分布及按停止原因统计的触顶比例；缺失字段注明未记录，不当作零。

### 样本统计：每个样本一行

| 分组 | 应包含的信息 |
| --- | --- |
| 样本信息 | 有效样本序号（不冒充原 Excel 物理行号）、样本编号、题目、状态及错误、视频路径与时长、指定与实际任务区间 |
| 实际配置 | 链路、算法版本、实际张数上限、采样率、评分；读取保存的配置，不能用当前默认值补旧记录 |
| 数量与结束情况 | 初始候选数、各实际阶段输入/输出数、最终张数、停止原因、是否因上限停止、已识别/覆盖/未覆盖与不确定图像片段数 |
| 最终图片 | 填写该样本的服务器最终图片目录绝对路径，不打包图片、不逐帧罗列；目录路径不等于本地电脑能够直接打开的路径 |
| 总体与阶段耗时 | 视频准备/下载等待、读取信息、视频指纹核对、抽帧合计、每题总耗时、各实际阶段及过程保存耗时；合计与其内部细项分组注明，不重复相加 |
| 局部分析概况 | 输入张数、总耗时、原位检查/匹配次数、参考比较次数、完整搜索次数、未匹配次数、严格核对次数、实际图案搜索次数、搜索结果缓存复用及图案准备复用次数、宽度不符计数、搜索线程上限 |
| 局部耗时定位 | 参考比较实际耗时、背景核对、其它准备、搜索位置累计、其中图案搜索累计、严格核对累计；累计工作时间可跨线程相加，不与实际经过时间相加 |
| 搜索预筛定位 | 搜索范围预筛次数、缩小范围/排除/回退/原图搜索次数、回退比例及预筛累计耗时；参考快速排除的检查、排除、宽度过滤、行统计准备次数及累计耗时 |
| 滑动检查概况 | 涉及图片数、比较次数、合并数、代表替换数、比较预算与是否用尽 |
| 最慢候选摘要 | 将已保存的最慢 3 张候选的编号、视频时间、局部耗时、区域尺寸及比较/搜索次数整理在本样本的摘要单元格中，不另建逐帧工作表 |

定位统计直接使用现有 `timings_s`、`local_analysis`、`selection` 及阶段记录，不新增视觉计算或逐帧导出流程。按列分组并固定常用列，较详细的定位信息放在后面的列；单位清楚标注。内容片段及未匹配次数不解释成遗漏的关键帧数量。

运行中导出时，以导出时状态生成快照；所有样本列出当前状态，未完成数据留空或注明未完成，不把正在写出的最终目录当作完成结果。导出不触发重跑、不改变原记录。历史缺字段使用“未记录”，有效零值照常保留。

下载文件名包含批次名、链路、上限、采样率和导出时间，并处理文件名不允许的字符。表内同时保留完整配置，不能只靠文件名区分实验。

## 实施覆盖范围

1. 页面输入、开始请求、算法配置快照、逐题调用与最终元数据传递一致；新增采样率必须实际生效。
2. 放开实验算法中配置校验、选择器、首尾与停止记录等位置的固定 15 截断，确保任意受支持上限都严格执行。
3. 新运行固定比例；历史旧权重结果继续可查看，base 不接受实验参数覆盖。
4. 批次列表、详情、每题配置与导出一致；输出数量统计适应可变上限，触顶仍按停止原因计算，不能按恰好 15 张计算。
5. 默认名称按本次创建时间与原输入文件名生成，字段显示有效值条件；新建重跑也生成新的默认名，原记录不变。
6. 单 XLSX 按批次概览与样本统计导出；已结束、运行中、有失败、重复编号、历史缺字段和样本级定位统计均需覆盖，不导出图片或逐帧清单。
7. 同步更新 README、当前技术方案、评分和上限使用说明，清楚区分当前能力与历史试验。

验收重点：填入超过 15 的张数后不能暗中仍按 15 执行；小数采样率可以正常传递；非法输入明确报错；默认名称包含正确创建时间和输入文件名；改变采样率后有效配置与候选准备确实改变；旧结果不受影响；XLSX 样本级数据、定位统计和最终目录路径与页面及原文件一致。

验证结果：v4.13 完整回归 237 项通过。与冻结 v4.12 完整重跑本地五题，默认15张/3fps的最终图片哈希、顺序、时间点、阶段数量和选择摘要均一致。新增用例验证2/10/15/25/40张上限、0.5/2.5小数采样、参数到执行的传递、非法值拒绝、配置命名、零值与缺失值区分、样本级定位导出、历史结果和失败/运行中状态。没有修改固定base或启动平台服务。
